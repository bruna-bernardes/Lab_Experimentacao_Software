# Katas Oficiais — Lab02

Os quatro katas deste diretório são os objetos experimentais utilizados no Laboratório 02.

Todos foram preparados com características semelhantes, buscando manter dificuldade comparável entre as tarefas:

- implementação em Python;
- regras de negócio objetivas;
- ausência de dependências externas;
- 10 testes de aceitação por kata;
- dificuldade compatível com o time-box de 35 minutos;
- problemas de domínio simples;
- preferência por exercícios autorais ou pouco indexados.

## Katas

1. `kata_01` — Tarifa de Entrega
2. `kata_02` — Cobrança de Estacionamento
3. `kata_03` — Processamento de Pedidos
4. `kata_04` — Classificação de Chamados por SLA

Cada pasta contém:

- `README.md` com o enunciado e as regras do problema;
- `solucao.py` com a assinatura inicial da função;
- `test_kata_XX.py` com os testes automatizados de aceitação.

As soluções dos katas não devem ser implementadas antes dos trials oficiais da Sprint 2.

## Teste auxiliar

A pasta `teste_runner` contém apenas um exemplo auxiliar utilizado para validar os scripts de execução dos trials e de coleta de métricas estáticas.

Ela não faz parte dos objetos experimentais oficiais do laboratório e não deve ser considerada como um quinto kata.
